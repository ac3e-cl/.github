# Support

## Getting Help

For questions about a specific repository, start with that repository's
`README.md`, documentation, and open issues.

Use GitHub issues for:

- Reproducible bugs.
- Documentation corrections.
- Feature requests within the scope of the repository.
- Questions that are useful to future users.

Contact AC3E at contacto@ac3e.cl for:

- Institutional or collaboration inquiries.
- Licensing and commercial-use permissions.
- Questions involving private data or restricted research material.
- Security reports, following `SECURITY.md`.

## What to Include

When asking for help, include:

- Repository name and link.
- Version, commit, branch, or release.
- Operating system and relevant environment details.
- Clear steps to reproduce the issue.
- Expected and actual behavior.
- Logs or screenshots when useful, with secrets removed.

## Maintainer Availability

Many AC3E repositories support active research projects. Response times may
depend on project activity, grant timelines, academic schedules, and maintainer
availability.
