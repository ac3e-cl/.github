# Security Policy

## Supported Projects

Security support is provided for active AC3E repositories maintained by current
AC3E members or collaborators. Archived repositories and historical research
artifacts may receive limited support.

Repository maintainers may define project-specific support windows. If a
repository has its own `SECURITY.md`, that file takes precedence.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities by email to contacto@ac3e.cl with:

- Repository name and affected version, branch, or commit.
- Description of the vulnerability and potential impact.
- Steps to reproduce or proof-of-concept details, when safe to share.
- Any known mitigations.
- Your contact information for follow-up.

## Response Expectations

AC3E will make reasonable efforts to:

- Acknowledge receipt within 7 calendar days.
- Assess severity and scope.
- Coordinate a fix or mitigation with relevant maintainers.
- Credit reporters when appropriate and desired.

Response times may vary depending on project activity, researcher availability,
and institutional review requirements.

## Public Disclosure

Please allow AC3E maintainers reasonable time to investigate and address the
issue before public disclosure. Coordinated disclosure helps protect users,
research participants, infrastructure, and collaborators.

## Sensitive Data

Do not include personal data, credentials, private keys, restricted datasets, or
other confidential information in public repositories, issues, discussions, or
pull requests.
